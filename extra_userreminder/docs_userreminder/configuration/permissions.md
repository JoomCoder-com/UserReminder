# Permissions

**Components > User Reminder > Options > Permissions** uses Joomla's standard access control (ACL). Set each permission per user group, like in any other Joomla component.

| Permission | Allows |
|---|---|
| **Access Administration Interface** | Opening User Reminder: dashboard, lists, opt-out, log, and the **Send Reminders** and **Send Test Email** buttons |
| **Configure ACL & Options** | Changing these options (the **Options** button) |
| **Delete** | Clearing and pruning the action log, and removing users from the opt-out list |

All screens show names and email addresses, so give access only to groups that may see them. Super Users have every permission.

The unsubscribe page on your site needs no permission: the code in the link identifies the user.
